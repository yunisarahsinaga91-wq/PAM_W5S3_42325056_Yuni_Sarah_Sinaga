# PAM W5S3 — Form and Navigation

Project Flutter praktikum Minggu 5 Sesi 3 untuk Yuni Sarah Sinaga (NIM 42325056).

## Isi aplikasi
- TextField nama dengan batas maksimal 21 karakter
- Dropdown bahasa pemrograman
- Dropdown gender
- Switch Connect Instagram
- Radio button gender
- Checkbox persetujuan
- Date picker tanggal lahir

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `PAM_W5S3_42325056_Yuni_Sarah_Sinaga` di VS Code.
3. Pastikan Flutter SDK dan emulator/perangkat Android sudah tersedia.
4. Jalankan terminal pada folder proyek, lalu:
   ```bash
   flutter pub get
   flutter run
   ```
5. Ambil screenshot tampilan awal dan setelah interaksi untuk dimasukkan ke laporan PDF.
